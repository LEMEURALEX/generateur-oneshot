# Générateur de one-shots

Générateur de plans de parties de jeu de rôle d'environ trois heures.
Le projet combine un moteur de règles déterministe et une IA locale pour produire un scénario structuré, modifiable et exportable en PDF.

> Statut : développement initial.

## Fonctionnalités prévues
- Génération d'un one-shot et suivi de sa progression
- Affinage du plan, verrous et historique des versions
- Bibliothèque de contenu personnel
- Export PDF en français ou en anglais

## Stack prévue
- Backend : Java 25, Spring Boot
- Frontend : React, TypeScript, Vite
- BDD : PostgreSQL
- IA locale : Ollama

## Documentation
Les instructions seront ajoutées davec les fichiers de configuration du projet.

## Sécurité et contenu
Ne jamais versionner de secrets ou de fichiers '.env'.
Le contenu du jeu doit être original, les marques, noms et textes protégés ne doivent pas être repris.
